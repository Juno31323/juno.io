# 플랫폼의 첫 테마

기존 대시보드의 Pretendard, 밝은 회색 바탕, 흰 패널, 파란 탐색 강조와 일정한 간격을 재사용합니다. UI/UX Pro Max의 Minimalism & Swiss Style과 Product Demo + Features 방향을 검토하고, 랜딩에 실제 첫 사용자의 게시본을 표시합니다. 영상·고객 수·성과 수치 같은 없는 자료는 만들지 않습니다. 자동 추천의 고급 부동산용 글꼴 조합은 맞지 않아 제외했으며 한국어 가독성 검색을 확인한 뒤 기존 자체 호스팅 Pretendard를 유지합니다.

서비스 셸과 개인 테마를 분리합니다. 서비스 메뉴는 가입·탐색·대시보드로 연결하고, 개인 페이지는 이름·소개·대표 작업을 먼저 보여 줍니다. 본문에는 프로젝트 카드, 소개, 연구, 이력, 글을 회원이 고른 순서로 배치합니다. 신규 계정의 작성 기능이 없는 기록 섹션은 기본적으로 숨깁니다.

포인트 색은 블루·포레스트·바이올렛·코랄 4개이며 각 밝기에서 대비가 확보되는 색으로 제한합니다. 회원이 CSS를 직접 입력하지 않습니다. 이미지가 없으면 빈 이미지 틀을 만들지 않습니다. 제목·소개·긴 기술 이름은 줄바꿈하며, 버튼과 링크는 키보드 초점을 유지하고 44px 이상의 조작 높이를 제공합니다. 섹션·프로젝트 순서는 위/아래 버튼으로 바꿉니다.

미리보기는 게시 전 초안이라는 안내를 표시하고, 1280px 또는 390px 뷰포트를 실제 iframe에 적용해 영역에 맞춰 축소합니다. 레이아웃이 실제로 바뀌지 않는 기기 모양 장식으로 대체하지 않습니다. 공개 범위, 프로젝트 탐색 허용, 초안 저장, 게시를 서로 구분하고 가까운 피드백을 제공합니다. API 오류나 충돌은 입력을 남깁니다.

공유 페이지의 제목·본문은 서버 권한 검사 후 생성합니다. 링크 공개는 개인 내용을 담은 OG를 만들지 않으며 비공개·회수 페이지는 같은 일반 안내를 표시합니다. 개인 이미지가 공개 정적 경로에 남지 않도록 비공개 미디어 프록시로 통일합니다.
